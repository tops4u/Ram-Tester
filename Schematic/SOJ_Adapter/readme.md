# SOJ Aapter

This Adapter add 2 SOJ 26 Sockets which allows for testing of 514256/514400 Style RAM and 511000/411000 RAM in SOJ Packages.

It also adds 2 ZIP Sockets, one for 511000/411000 RAM in ZIP Package and the other for 41256 RAM in ZIP Package.
